✈️ Baca soal, lalu kemudikan pesawat ke kiri/kanan menuju gerbang cincin A, B, C, atau D yang berisi jawaban benar.

⭐ Jawaban benar = 100 poin. Jawaban salah = 0 poin, jawaban benar ditampilkan.

  • Pemain 1: tombol A dan D
  • Pemain 2: tombol panah ◀ ▶
  • Pemain 3: tombol J dan L
  • Pemain 4: Numpad 4 dan 6
  • Pemain 5: Q / E • Pemain 6: U / O • Pemain 7: Z / C • Pemain 8: B / M
  • HP/layar sentuh: tombol ◀ ▶ di area masing-masing
  • Jeda: tombol ⏸ atau tombol P / Esc (semua pemain)
  • Jeda pribadi: tombol ⏸ Jeda di area masing-masing, atau tombol S / ↓ / K / Numpad 5 / W / I / X / N (pemain 1–8). Berguna untuk membaca soal dan pilihan jawaban.
